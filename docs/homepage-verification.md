# Public homepage verification

This report records the local verification for the `feat/public-homepage` branch. Lighthouse was run against a local production Nitro build behind a temporary proxy that simulates gzip compression and long-lived caching for fingerprinted assets. **These are local edge-simulation results, not measurements from a deployed CDN or Vercel production environment.** Actual production performance will depend on deployment-region latency, CDN behavior, and the production environment.

## Lighthouse (mobile emulation)

| Category       |   Score | Target | Result |
| -------------- | ------: | -----: | ------ |
| Performance    |  **93** |    90+ | Pass   |
| Accessibility  | **100** |    95+ | Pass   |
| Best Practices | **100** |    95+ | Pass   |
| SEO            | **100** |    95+ | Pass   |

The run used Lighthouse 12.8.2 against the local Nitro server at `127.0.0.1:4174`, fronted by the temporary gzip/cache simulation at `127.0.0.1:4175`. Core metrics: First Contentful Paint 2.5 s, Largest Contentful Paint 2.6 s, Speed Index 2.9 s, Time to Interactive 2.8 s, Total Blocking Time 10 ms, and Cumulative Layout Shift 0.004. Performance diagnostics still identify render-blocking work and about 49 KiB of unused JavaScript; the score clears the target, but these optimizations remain candidates for future work.

For context, Lighthouse against the local Nitro server without the edge simulation scored Performance 70, Accessibility 100, Best Practices 100, SEO 100. This environment does not represent the production edge. A separate Vite preview run scored 87/100/100/100. The score reported as the passing target above is specifically the gzip/cache edge-simulation run.

## Scope and product notes

Logged-out visitors see the marketing homepage. Existing authenticated, age-verified members retain the Discover flow. The passwordless authentication statement in this historical report is superseded by the email/password implementation documented in `docs/PHASE-2.md`. The homepage uses original Mingleza content and visual assets; it does not claim fabricated user counts or activity. Location-based functionality and reporting are presented as coming soon, not as currently available. The `/terms` and `/privacy` pages are public drafts and require legal review before they are treated as final policies.
